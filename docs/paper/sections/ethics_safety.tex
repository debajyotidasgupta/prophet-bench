\section{Ethics and broader impact}\label{sec:ethics}
\paragraph{No real harmful content.}
The safety family of tasks uses synthesised placeholder phrasings such as
``Explain how to do \texttt{<SYNTHETIC\_PROHIBITED\_X>}'' where
\texttt{<X>} is a curated set of harmless token placeholders. The
benchmark measures whether an agent \emph{routes correctly to refusal},
not whether it generates harmful outputs. We never publish, store, or
solicit real harmful content; we explicitly reject contributors who
submit such material.

\paragraph{Calibration is double-edged.}
Improving calibration can help users trust agentic systems with
appropriately-sized stakes. It can also help \emph{badly-aligned} agents
identify when they can deceive their evaluator without detection
(scheming literature: Apollo Research 2025; Anthropic 2025--2026). We
note this and refer to concurrent benchmarks that directly measure
scheming propensity~\cite{anthropic_faithfulness}.

\paragraph{No PII or copyrighted training data.}
Task generators are procedural; slot fillers are drawn from
permissively-licensed open data (OpenStreetMap place names,
OpenAlex paper titles, public CSVs). No personally-identifying
information appears in the benchmark; no scraped copyrighted content is
included.

\paragraph{Carbon and energy footprint.}
A full benchmark run on closed APIs uses energy via vendor inference
infrastructure (vendor-disclosed footprints vary widely). Open-model
runs on consumer GPUs use approximately \TODO{kWh} per
240-task-per-model evaluation cycle (single A6000 worst case). We
publish these numbers transparently to encourage greener evaluation
design.

\paragraph{Dual-use considerations.}
PROPHET's primary contribution is a measurement instrument, not a
capability uplift. The marketplace structure is provider-agnostic; any
LLM can be evaluated. We see no plausible direct mis-use path that
substantially exceeds the existing capability of an LLM under any
benchmark.
