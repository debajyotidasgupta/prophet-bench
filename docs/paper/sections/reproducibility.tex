\section{Reproducibility appendix}\label{app:reproduce}

\subsection{One-command reproduction}
The full headline table and all paper figures reproduce from a single
release seed plus the Pareto-essential multi-seed rotation:
\begin{lstlisting}[basicstyle=\small\ttfamily, frame=single]
git clone https://github.com/debajyotidasgupta/prophet-bench.git
cd prophet-bench
make install
cp .env.example .env       # add OPENROUTER_API_KEY etc.
make run-paper             # Standard tier full panel, seed=42
make run-paper-hard        # T_extreme + multi-seed essentials
make finalize-paper        # regenerate figures + tables + paper text
make paper                 # compile PDF (requires LaTeX)
\end{lstlisting}
Wall-clock on a single workstation (M2 Pro, 32 GB RAM) with 8 concurrent
API calls: approximately 90 minutes for the Standard-tier panel and a
further 2--3 hours for the T\textsubscript{extreme} multi-seed
Pareto-essentials. Total OpenRouter spend: \$34.65 USD across the
two-tier matrix (Standard \$25.58 + T\textsubscript{extreme} multi-seed
\$9.07).

\subsection{Model version pinning}\label{app:model-versions}
OpenRouter routes a model slug (e.g.\ \texttt{openai/gpt-5}) to the
provider's currently-served checkpoint. Vendors update checkpoints
without renaming, so a re-run six months later may dispatch to a
different backend. The benchmark therefore pins the experimental run
to a \emph{date}, not a checkpoint hash. \autoref{tab:model-versions}
documents the served checkpoint for each model in our headline matrix
as of the run date.

\subsection{Statistical details}
\paragraph{Bootstrap}
Every aggregate metric (accuracy, ECE, Brier, log-loss, net payoff) is
reported with a percentile bootstrap 95\,\% CI, $B = 10^4$. BCa
correction is available via the \texttt{--bca} flag.

\paragraph{Paired tests}
Two-system comparisons use paired tests on the same per-task outcomes.
For each metric:
\begin{itemize}
  \item Continuous (payoff, log-loss): paired Student's $t$ ($n \ge 30$)
  or paired Wilcoxon signed-rank.
  \item Binary (correct/incorrect): McNemar's exact.
  \item Group-level (ECE, Brier): permutation test, $B = 10^4$.
\end{itemize}

\paragraph{Multiple-comparison correction}
By default we apply Holm--Bonferroni across all pairs $\times$
metrics; we also report BH-FDR-adjusted $p$-values in parallel.

\paragraph{Effect sizes}
Every $p$ is accompanied by an effect size: Cohen's $d$ for paired $t$,
rank-biserial $r$ for Wilcoxon, paired odds-ratio for McNemar,
$|\Delta\ECE|$ for permutation.

\paragraph{Power analysis}
For each headline contrast, we report post-hoc power and the minimum-
detectable Cohen's $d$ at $\alpha = 0.05$, power $= 0.80$.

\subsection{Hardware and environment}
\begin{itemize}
  \item Python 3.11.12 on macOS 25.3 (Darwin) for development.
  \item Reproducibility CI runs on Ubuntu-22.04 GitHub Actions with
  Python 3.11 / 3.12.
  \item All seeds derive from \verb|cycle_seed=42| via SHA-256 hashing
  (see \texttt{prophet.utils.seed}).
  \item Closed-model APIs accessed via OpenRouter
  (\url{https://openrouter.ai}); see
  \texttt{src/prophet/agents/openai\_compat.py}.
  \item Inference budget enforced by \verb|PROPHET_MAX_RUN_COST_USD| at
  both the orchestrator and per-API-call levels.
\end{itemize}

\subsection{Gaming-resistance audit}\label{app:audit}
We run the Berkeley RDI April 2026 attack family against the released
benchmark:
\begin{description}
  \item[\texttt{conftest.py} hijack] \(N/A\) --- PROPHET runs no test
  harness in the agent's scope.
  \item[\texttt{file://} retrieval] \(N/A\) --- no retrieval pipeline.
  \item[Empty-JSON wrapper] blocked --- verifiers require typed answers
  and reject empty objects.
  \item[Curl trojan in shell sandbox] \(N/A\) --- code family runs
  candidate Python only, not shell.
  \item[Training-data leakage] mitigated by procedural seeds (every task
  is deterministically generated from a $(\text{family}, \text{seed},
  \text{difficulty})$ tuple, so the public seed list is the entire
  visible surface). The seed rotation cadence is a v2 commitment, not
  executed for this submission; the released seeds are documented as
  ``frozen for reviewer reproducibility'' rather than ``contamination-proof''.
\end{description}
